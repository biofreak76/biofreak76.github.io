Editorial principles

1

Separate evidence from assumptions. A model is only as useful as its treatment of uncertainty.

2

Connect scientific risk to financial value. Biology, trial design, adoption, and reimbursement enter through different channels.

3

Prefer decision-useful summaries. Each reference should leave the reader with a practical analytical tool.

Working notes

Thoughts on valuation

Short arguments and interpretive notes. These can later become longer essays, case studies, or company-specific valuation memos.

Thought 01

rNPV is a baseline, not a conclusion.

Probability-adjusted cash flow is useful for disciplining assumptions, but a single success probability can conceal timing, branching decisions, correlated risks, and the value of learning. The model should show where uncertainty enters.

Thought 02

A development gate changes the information set.

The value before a trial is not merely the value after the trial multiplied by the probability of success. Passing a gate changes what is known, what can be financed, and which strategic choices become available.

Thought 03

Diagnostics should not be valued like therapeutics.

Technical validation is only one layer. Workflow integration, physician behavior, reimbursement, test frequency, evidence requirements, and platform economics can dominate the commercial outcome.

Thought 04

Project value and company value are different objects.

A scientifically attractive asset may sit inside a poorly financed company. Company valuation must also account for cash runway, dilution, platform overhead, licensing obligations, capital needs, and management's portfolio choices.

Editorial workflow

How each source is reviewed

From reading to analytical use

A consistent review format makes the collection useful for equity research, project valuation, and future writing.

  1. Question
    What valuation problem is the source trying to solve?
  2. Model
    What assumptions, equations, or decision structure does it use?
  3. Biotech interpretation
    How do scientific, clinical, regulatory, or adoption risks enter?
  4. Practical test
    Where would the method work, and where could it mislead?
